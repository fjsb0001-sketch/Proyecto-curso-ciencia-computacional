# Proyecto-curso-ciencia-computacional
Utilizando dataset público sobre viviendas protegidas por comunidad autónoma desde 1991, se realiza un pequeño análisis exploratorio. Aporta números sobre los datos analizados (número de filas, número de columnas, valores promedio, mínimos o máximos de las variables cualitativas, valores más frecuentes de las variables cuantitativas).
